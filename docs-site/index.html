Capabilities

What your agent gets

Paper search & dedup

Parallel search across OpenAlex, Semantic Scholar, Crossref, arXiv, PubMed/Europe PMC, DBLP, DOAJ, INSPIRE-HEP, Scopus, WoS and 12+ society publishers — merged by DOI, arXiv ID and title fingerprint, with reconstructed abstracts, TLDRs and OA PDF links.

Journal impact metrics

ISSNs, APCs, DOAJ status, h-index, i10-index and 2-year mean citedness from OpenAlex, enriched with Elsevier CiteScore / SJR / SNIP and Clarivate JCR Impact Factor, JCI and Q1–Q4 quartiles when keys are configured.

Canonical BibTeX

Official entries via universal DOI content negotiation, arXiv, DBLP and INSPIRE-HEP, with deterministic synthesis as a fallback — never a hallucinated citation key.

4-tier full-text context

Semantic Scholar 500-word snippets → arXiv LaTeXML HTML → NCBI PMC BioC JSON → legal OA PDF extraction, ranked against your focus query to keep the prompt window small.

Citation graphs

Forward citations and backward references via OpenAlex and OpenCitations, including influential-citation counts and self-citation flags.

Zero-key open core

The open scholarly graph works with no API keys — including OpenAlex's free singleton enrichment and automatic DBLP Anubis challenge solving — while optional keys unlock commercial tiers.

Quickstart

Up in three commands

shellinstall
git clone https://github.com/raktim-mondol/academic-search-api
cd academic-search-api
pip install -e .
shellCLI
# search papers with abstracts, PDFs, citations & BibTeX
acadsearch papers "Attention Is All You Need" \
  --limit 3 --format markdown

# journals with impact metrics
acadsearch journals "Nature Machine Intelligence" \
  --limit 3 --format markdown

# official BibTeX for any identifier
acadsearch bibtex "10.1038/nature14539"
pythonSDK
from acadsearch import AcademicSearchClient

client = AcademicSearchClient()

papers = client.search_papers(
    "Vision Transformer", year_min=2020, limit=5,
    sort="citations",
)
for p in papers.results:
    print(p.title, p.doi, p.citation_count)
    print(p.abstract)
    print(p.bibtex)

ctx = client.get_pdf_context(
    "arXiv:1706.03762",
    focus_query="scaled dot-product attention",
)
print(ctx.full_text_excerpt)
shellserve
# FastAPI REST + Streamable HTTP /mcp on :8000
acadsearch serve --port 8000

# OpenAPI 3.1 spec at /openapi.json
# Swagger UI at /docs

# MCP stdio server for Claude Code / Cursor
claude mcp add acadsearch -- \
  python3 -m acadsearch.mcp_server

Context extraction

The 4-tier full-text cascade

Deep section-level paper context without flooding the prompt window or corrupting multi-column PDFs.

  1. 1

    Semantic Scholar snippets

    ~500-word body-text passages from /graph/v1/snippet/search, ranked against your focus query.

  2. 2

    arXiv LaTeXML HTML

    Native arxiv.org/html and ar5iv sections, tables and equations for any paper with an arXiv ID.

  3. 3

    NCBI PMC BioC JSON

    Structured TITLE, ABSTRACT, INTRO, METHODS, RESULTS, DISCUSS passages for biomedical papers, plus PubTator 3.0 full-text export.

  4. 4

    Legal OA PDF extraction

    Wiley TDM, ScienceDirect and Springer JATS full-text APIs when keyed; otherwise Unpaywall-resolved PDFs parsed with pypdf.
